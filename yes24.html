01

인터뷰 인사이트

경쟁 서비스 수준은 기본
굿노트와 콴다 수준은 갖추고, 킬러 기능은 정확도와 반응 속도에서 앞서야 한다.
AI는 뷰어 안에서
서재 같은 일반 영역이 아니라, 참고서를 보는 중에 해설을 따로 찾지 않고 바로 확인하게.
데이터 제작 흐름부터
원본(HWP, PPT)에서 PDF, 문제 DB로 이어지는 문항 데이터 제작과 디지털 조판 프로세스 정비가 필요.
고객이 꼽은 AI 기능 우선순위 Top 5
  1. 1. 질의응답 (음성 포함)
  2. 2. 개념 설명 요약
  3. 3. 힌트 및 해설
  4. 4. OCR과 유사 문항 추천
  5. 5. 해설 내 연계 개념 연결
02

AI 기능 5종

학습 플래너
목표 등급과 시험 일정, 학습 가능 시간을 입력하면 참고서와 오답노트 범위로 계획을 자동 생성. 캘린더, 할 일, 타임라인 뷰를 제공하고 진행률에 따라 일정을 재조정.
오늘의 학습 미션
학생의 현재 상태와 일정을 보고 오늘 할 일을 우선순위로 정렬해 제시.
힌트와 추천 학습
1~3단계 힌트와 난이도별 개념 해설, 유사 문항과 추가 콘텐츠 추천. 참고서 기반 RAG로 “이 문제 관련 개념 알려줘”에 응답.
핵심 노트 생성
3분, 10분, 키워드, 시험 대비 형태로 요약 노트 생성. 과목별 템플릿(연표, 마인드맵, 공식)과 TTS 요약도 제공.
학습 리포트
과목 커리큘럼 대비 현재 상태를 분석해 대시보드와 맞춤 메시지로 제공.
