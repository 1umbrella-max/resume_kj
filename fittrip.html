현지인이 여행 코스를 대신 짜주는 역경매 여행 플랫폼을 기획해 예비창업패키지 선정, 지원금 5,500만 원을 확보했습니다.

역할 및 기여도

  1. 1IA와 기능 명세지도 API 연동 장소 DB 구조와 주요 기능 정의
  2. 2역경매 BM 설계여행객 요청에 가이드가 입찰, 에스크로 결제와 수수료
  3. 3여행 UX지도 기반 동선 시각화, 동행 모집, 일정 공동 편집
  4. 4운영과 출시가이드 자격 검증 어드민, QA, v1.0 스토어 배포

성과

문제와 해결

기존 문제설계한 해결
  • 여행지 정보를 직접 찾아 입력하는 피로감→취향만 입력하면 현지인이 코스를 제안
  • 기록용 도구라 수익 모델이 없음→코스 거래 수수료 기반 C2C 비딩 모델
  • 텍스트 일정표로는 동선 파악이 어려움→지도 API 동선 시각화와 피드형 UI
  • 일정을 캡처해 메신저로 공유하는 번거로움→일정 초대와 실시간 공동 편집
